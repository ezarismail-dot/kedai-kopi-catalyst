# Kopi Tegalan – Website Katalog Kedai Kopi

Website statis katalog kedai kopi fiktif "Kopi Tegalan" yang menampilkan profil kedai, daftar menu dengan filter kategori, dan kontak pemesanan. Dibuat sebagai Final Assignment **Weekly Meet Catalyst – Build Together: Collaborative Mini Project**.

## Tujuan Project

Membuat website katalog sederhana untuk kedai kopi lokal sekaligus berlatih alur kerja kolaborasi di GitHub: pembagian task lewat Issues, branch, commit, Pull Request, dan review.

## Section yang Tersedia

- **Home / Hero:** nama kedai, tagline, dan tombol navigasi.
- **About:** cerita kedai, visi, misi, dan jam buka.
- **Menu (Main Content):** kartu menu kopi, non-kopi, dan makanan dengan filter kategori.
- **Contact & Footer:** alamat, WhatsApp, Instagram, dan tautan pendukung.

Fitur tambahan: menu hamburger untuk tampilan HP dan filter menu dengan JavaScript.

## Teknologi yang Digunakan

- HTML
- CSS
- JavaScript dasar
- Git dan GitHub

## Cara Menjalankan Website Secara Lokal

1. Clone repository:
   ```
   git clone https://github.com/[username]/[nama-repo].git
   ```
2. Masuk ke folder project:
   ```
   cd [nama-repo]
   ```
3. Buka file `index.html` di browser (klik dua kali). Tidak perlu server atau instalasi tambahan.
